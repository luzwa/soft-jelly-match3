## 3. 本轮新增：计分（增补 V2 §4–11，`js/score_service.js`，`jelly_score_v1`）

- 只吃核心已提交的结果：每波提交（真实移除的计分身份、糖霜真实减少层数、箱子真实 HP 变化与归零、真实解除的绑带、自然生成）、送达提交、动作结束、终局。动画、对象销毁、目标栏飞入、结算清场都不发分。
- 计分身份 `tok`（scoreTokenId）：初始/补入的果冻各有一个；普通升格为特殊时沿用锚点的身份；彩虹转换不产生新身份。第一次真正移除时领一次 100（账本里有已领集合兜底）。
- 每波：基础分合计 × 连消百分比（100/150/200/250/300，第 5 波起封顶）向下取整；新波 = 本波结清 → 重力/送达/补位稳定 → 出现新匹配（与核心的波次定义一致；同一波的接力触发不升倍率）。
- 固定加分：自然制造 线 300 / 区域 500 / 彩虹 800（补位产生的也发；彩虹转换产物不发）；主动特殊＋特殊组合 1000/1600/2200/3200/4000/5000（只在第 1 波、只一次；彩虹＋普通不是主动组合）；送达 1000；技巧连击 0/300/700/1200/1800（第 5 次起封顶）；通关 2000 + 剩余步数 × 500（一次确定，幂等）。
- 技巧连击：只看被接受的耗步交换——首轮（玩家交换直接形成的第 1 波）实际制造 ≥1 颗特殊，或主动特殊＋特殊组合 → +1（一次操作最多 +1）；其他有效耗步交换（含彩虹＋普通、单独用一颗特殊、只有补位造出特殊）→ 归零。成功使用盘外道具 → 归零并记辅助；无效/取消/被拒 → 不变；免费自动洗牌 → 不变、不加分。核心没有时间输入，所以思考、暂停、切后台不会断连。
- 盘外道具引起的清除照常计分，从第 1 波起算，账本 `assist` 记录次数（个人纪录区分“无道具最佳”）。
