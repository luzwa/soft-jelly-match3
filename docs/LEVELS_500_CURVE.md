## Royal Match 节奏（适配本引擎）

1. **学 → 考 → 缓**：新组合先松后紧；**硬关后连着几关偏易**（不是只放松一关）。
2. **区内峰值**：每 50 关区切成两段「地图」≈20+20；每段中部（约第 8–12、28–32）难度抬头，段末（18–20、48–50）送礼物/放松。
3. **可预期尖刺**：每段约在 offset **5 / 10 / 15**（及 +20）放 hard；偶发 **super-hard** 在 10 或 15；其后 2–3 关降压。
4. **后期不加新障碍类型**：只用 frosting_pad / cookie_crate / gummy_tie / delivery_basket+exits / collect / playableMask `#` / 4–5 色池 / 道具配额。
5. **步数经济**：前松后紧（见下表）；后期「差一点通关」靠目标密度与盘面，不靠新机制。

## 命名方案

- **Z1**：保持 `c1_01`…`c8_08`，`chapterId` = `ch1`…`ch8`（进度从第 1 关解锁逻辑不变）。
- **Z2–Z10**：`z0N_01`…`z0N_50`，展示名 `{全局序号} · {短标题}`，例如 `51 · 糖霜回廊`。
- **全局序号** = `(zone-1)*50 + indexInZone`（Z2 的 01 → 51）。

## 模板族（生成器）

1. `frosting_field` — 霜铺量/双层比随区升  
2. `crate_wall` — 横墙、围栏、棋盘格箱  
3. `tie_lattice` — 绑带点阵 / 对角  
4. `delivery_lane` — 果篮列 + 底出口 + 途中箱/绑/霜  
5. `mask_hourglass` / `mask_islands` / `mask_stairs` / `mask_narrow` — 异形  
6. `multi_mix` — 2–4 目标组合  

参数：障碍格数、2HP/2 层比例、是否 P4、目标组合、seed = `zone*1000+idx`。
