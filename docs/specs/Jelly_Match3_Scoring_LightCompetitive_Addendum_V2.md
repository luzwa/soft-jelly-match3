高分追求由三部分组成：单次操作内连续消除、玩家主动制造与组合特殊棋子、跨有效操作的技巧连击。技巧连击没有倒计时，思考和暂停不会断连。

本轮提供的视频长约 95.08 秒，尺寸 430×960，只有视频轨。审查了全片间隔关键帧，以及约 64–71 秒、81–87 秒的密集采样。未上手操作当前游戏；编码帧率不等于实机渲染性能，不能据此宣布帧率达标。

### 2.1 彩虹＋特殊的完整含义

例如彩虹与黄色划线交换：选择普通黄色果冻，把它们变成划线并发动。两颗源特殊单独登记为本组合能源，消费一次，不再各自多发动一次。

- 触发时冻结对方底色、转换实例和位置。
- 特殊的底色必须能辨认，不能用所有特殊统一一种颜色导致玩家无法计划。
- 保留当前合法的转换、绑带解除与目标计数行为，所有实际差异写入 RULE_DECISIONS.md。
- 转换产物按组合计划触发；不计为玩家又自然制造了几十个四连，不发几十次组合奖。
- 本轮新增边界规则：若该选色没有任何可转换普通果冻，组合无效，不扣步、不吞掉源特殊；不得静默换到场上最多颜色。合法步检测也不得把此组合列为可走一步；这不是对既有 v2 行为的已验证描述。
- 目标集合不能在动画过程中重新查询，以免新补入同色又被无限加入。

### 2.2 禁止单点引爆后，合法步检测也要同步

合法步检测不能把“点击某个特殊就能继续”作为可用操作。它必须枚举当前真的允许的交换、匹配触发、彩虹交换和特殊组合。

也不能由“不能单点”推断“所有特殊与任意邻格交换都会引爆”。继续使用 v2 已有的明确触发约定。

### 2.3 阶段 A 四条的处理

Builder 从实际代码、阶段 A 报告或项目交接文件中补录四条：旧规格、当前行为、保留原因、验证案例和规则版本。优先级为本轮明确决定 > 已补录的 v2 规则 > 旧规格默认建议。

没有内容来源时如实列为未补录，保持现状；选关、目录、存档和非依赖工作可以继续。评分适配依赖真实事件语义的部分必须核对，不以“四条已通过”代替检查。

## 3. 已知问题如何处理

### 3.1 箱子和绑带下面空着

先分清视觉空缺和逻辑供给：

1. 有效格即使没有棋子，也必须绘制完整托盘底格，不能当 void 或透明洞绘制。
2. 固定物阻挡重力时，下方短暂空格可以是正常规则结果；不能为了填满而在阻挡下方临时创造出生口。
3. 开局可以按关卡数据预填固定物下方的棋子，不必让全部初始内容从顶部物理落入；后续补子仍遵循正式入口。
4. 检查静态可玩段的出生口、固定阻断和解除后的供给。正式关避免大量无法恢复补给的区域。
5. 编辑器显示受阻区域和警告，功能验证关可以保留极端摆放。

仅补一张地板图不能证明供给问题已经修复；反过来，规则允许的暂时空格也不应被“自动补子穿箱”掩盖。

### 3.2 vb_03 / vb_04 一步过关

保留为单项规则验证夹具。一步验证一个明确规则是合理的；它们不计入正式 30 关，也不作为关卡难度已完成的证据。

验证入口保留“规则测试，非正式内容”标记；测试关不写正式进度、星级或挑战成绩。

### 3.3 两个未调难度的示例关

保留为草稿。进入正式目录前，需要具体设计意图、结构校验、正常操作试玩与难度修订记录。新计分尺度生效后重新设置星级阈值，不沿用旧的小分数门槛。

## 4. 计分公式：一个乘区，其余固定加分

每次有效操作的得分：

```text
actionScore
  = Σ floor(waveBaseScore × cascadePercent / 100)
  + naturalSpecialCreationBonus
  + activeSpecialComboBonus
  + deliveredBasketCount × 1000
  + skillStreakBonus

成功时 finalScore
  = runActionScore + 2000 + remainingMoves × 500
```

只有波次基础分参与连消倍率。制作奖励、主动组合、果篮、技巧连击和终局奖励均为加法，不再相乘。

失败不发通关与余步奖励。解锁以完成关卡目标为准，不追加隐藏分数要求。玩家已获得的分数不会因为技巧断连而扣回。

### 4.1 基础分

| 实际提交的事件 | 基础分 | 规则 |
| --- | ---: | --- |
| 一颗普通/特殊棋子真正被移除 | 100 | 每个计分身份只领一次；升格暂时不算移除，见下一节 |
| 糖霜实际减少一层 | 100 | 按真实层数变化，不按攻击来源数量 |
| 箱子实际减少一点耐久 | 150 | 耐久没有变化就没有分 |
| 箱子最后一点归零 | 额外 150 | 摧毁奖励一只箱子只领一次；最后一击共 300 |
| 绑带真实解除 | 200 | 宿主若真正被移除，可另领其 100 分 |

果篮送达固定 1000，单独计入，不放进本表的连消乘区。

只有规则提交的匹配消除或攻击消费才能兑付棋子基础分。通关清场、重开、切关、场景卸载、对象回收及离场代理销毁不兑付计分身份。例如通关时还留有 5 颗特殊，结束界面清空棋盘不能因此再加 500 分。评分订阅规则结算事件，不订阅通用对象销毁事件。

“目标进度＋1”本身不额外发分。普通果冻清除、任务栏更新、动画飞入 HUD 不能各发一笔相同分数。

### 4.2 特殊生成锚点：目标计数与评分分开

录屏展示了既有锚点计收集规则：原普通果冻升级为特殊时，可以按现行规则计一次收集。保留该目标规则。

新评分采用另一条明确约定：锚点升级属于转换，暂时不发该颗棋子的 100 基础分；之后特殊真正被移除才发一次 100 分。自然制作奖励在生成时照常发。

实现 scoreTokenId：

- 每个新生成或初始摆放的普通/特殊棋子获得一个计分身份。
- 普通升格为特殊、彩虹转换、换渲染对象时延续该计分身份。
- 实际运行对象可以获得新的 instanceId，但不得因此获得新的基础计分机会。
- 计分身份第一次真正被移除时领取一次 100 分，随后任何回调或离场代理不再得分。
- 彩虹转换后立刻发动：每个原对象最终仍只得到一次 100 分。
- 新补入的普通果冻是新身份，可以正常得分。

不要直接把所有 basePieceConsumed / 目标收集事件都映射为 100 分。必须识别“真正清除”与“升级转换”的原因，避免改坏现有目标系统或重复入账。

## 5. 单次操作内的连消倍率

| 消除轮数 | 基础分倍率 |
| --- | ---: |
| 第 1 轮 | ×1.0 |
| 第 2 轮 | ×1.5 |
| 第 3 轮 | ×2.0 |
| 第 4 轮 | ×2.5 |
| 第 5 轮及以后 | ×3.0 |

连消段数可以继续增加，倍率封顶。后续每轮仍对实际清除得分，所以高连消持续有收益。

新波次的唯一判定是：本轮匹配和特殊连锁结清 → 重力、送达、补位稳定 → 形成新的匹配。

以下均不是新波次：

- 一颗划线接力触发另一颗特殊。
- 同一轮攻击多个区域或路径交叉。
- 将一次爆炸分成多个动画播放。
- 延迟 100 毫秒才显示第二条得分。
- 分数滚动多刷新了几帧。

新玩家操作从第 1 轮重新计算。盘外工具引发的清除可以在普通闯关计分，但单独从第 1 轮开始，并标记辅助使用。

UI 显示“8 连消 · 得分×3”，不能继续把“连消×8”当成未解释的倍率字样。

## 6. 自然制造特殊的固定奖励

| 匹配结果 | 制作奖励 |
| --- | ---: |
| 四连实际生成划线 | +300 |
| T/L 实际生成区域特殊 | +500 |
| 五连实际生成彩虹 | +800 |

- 依据匹配结算器已提交的自然生成事件，不让评分器另扫棋盘判断。
- 同一个匹配组只按实际生成结果发一次奖；五连不同时叠领四连和五连奖励。
- 一次操作形成多个独立组且各自生成特殊，可以分别发制作奖。
- 自然补位产生的特殊也领制作奖，但不替玩家增加技巧连击。
- 彩虹批量转换出的特殊不领制作奖。
- 制作奖励不乘连消倍率。

## 7. 主动特殊组合奖励

| 玩家主动组合 | 固定奖励 |
| --- | ---: |
| 划线＋划线 | +1000 |
| 划线＋区域 | +1600 |
| 区域＋区域 | +2200 |
| 彩虹＋划线 | +3200 |
| 彩虹＋区域 | +4000 |
| 彩虹＋彩虹 | +5000 |

奖励叠加在实际范围清除所得分数之外，一次源组合只领一次。

- 必须是玩家主动提交的合法特殊＋特殊交换。
- 同一轮被动引爆多个特殊，不伪装成多次主动组合。
- 彩虹转换 20 颗划线，仍只有源头一次彩虹＋划线奖励。
- 不另加“每次特殊触发奖励”，以免转换链重复堆奖。
- 源特殊真正移除时可按自己的 scoreTokenId 领基础分，组合奖是另一个明确事件。
- 大范围覆盖同一颗棋子，只按其真正移除领一次基础分。

## 8. 跨操作的技巧连击

命名为“技巧连击”，与同一步中的自动连消分开。

一次耗步的有效操作满足以下任一条件，技巧连击增加 1：

1. 玩家交换直接形成的首轮匹配实际制造了至少一颗特殊。
2. 玩家主动交换两颗特殊，成功发动组合。

一操作最多增加 1，无论制造或连锁了多少颗。

| 连续技巧操作次数 | 本次额外加分 |
| --- | ---: |
| 第 1 次 | +0 |
| 第 2 次 | +300 |
| 第 3 次 | +700 |
| 第 4 次 | +1200 |
| 第 5 次及以后 | +1800 |

连续次数继续记录，奖励在第 5 次封顶。显示“技巧3连 · +700”，不显示容易误解的“分数×3”。

### 断连与保留

- 没有倒计时，思考、暂停、切后台、查看规则不会中断。
- 有效耗步的普通三消若不满足条件，技巧连击归零，但所有正常分数照领，已获分不扣回。
- 单独使用一颗特殊或彩虹＋普通，本身不满足本版技巧链条件；依然可以获得范围清除和连消分。
- 自动补位偶然造出特殊，不使一笔普通操作变成主动技巧操作。
- 无效交换、取消和单点选中不增加，也不重置。
- 成功使用盘外工具后技巧连击归零；无效或取消使用不重置。
- 免费自动洗牌不加分，不增技巧链，也不重置已有链。

断连采用轻微收回提示，不播放失败警报，不施加倒扣。普通闯关不要求玩家维持技巧链才能通关。

## 9. 果篮、锤子与终局

### 9.1 果篮送达

只在 deliveryCommitted 时发固定 1000 分。出口进入、飞向目标栏、动画销毁均不再次计分；每个果篮身份只送达一次。

同一操作多个果篮连续到达出口，各发一次，并在显示层合并成“送达2个 +2000”。不为了把送达放到第 8 段而提高送达分。

### 9.2 锤击果篮下的糖霜

若地垫有两层，小锤使其 2→1，耗一次小锤，得地垫基础分 100；果篮仍在原位，送达分为 0。

若只有一层，则移除该层，同样耗一次小锤、得 100。若没有可受击地垫，且果篮免疫该攻击，选择无效，不耗库存、不发分。

这一局记录辅助道具使用。正式无道具挑战不可使用盘外锤子。

### 9.3 通关与余步

当前动作全部连锁、重力、送达稳定后，若目标完成，停止接收新操作并一次性确定：

```text
winBonus = 2000
remainingMovesBonus = remainingMoves × 500
finalScore = actionScoreTotal + winBonus + remainingMovesBonus
```

余步奖励提供早通关的价值；有限步数内选择晚一点完成最后目标、先制造更好的组合，也允许成为追分策略。不得在已经判定通关后继续自由操作刷分。

不用新的随机终局爆炸计算第二份奖励。如果将来将余步演成特殊棋子，它们只是确定奖励的演出，不再次修改棋盘目标、连消、技巧链或分数。

跳过结算、重开、恢复页面、重复回调都不能重复发奖励。失败不发 winBonus 和 remainingMovesBonus。

## 10. 可核对的评分例子

这些是合成验收样例，不是当前游戏实测分数。

### A. 普通三消

3 颗真正移除：3×100=300。

### B. 主动四连

3 颗移除，1 颗锚点升级留场：3×100+300 制作奖=600。

若是连续第 2 次技巧操作，再加 300，本次 900。锚点按既有规则可以计收集，但评分基础 100 留待其真正移除。

### C. 主动五连

4 颗移除，1 颗锚点升级：4×100+800=1200。不能同时再领四连奖。

### D. 划线＋区域，并接一次补位连消

- 第 1 轮真正移除 12 颗，包含两个源特殊：1200。
- 第 2 轮真正移除 6 颗：600×1.5=900。
- 主动组合奖：1600。
- 连续第 3 次技巧操作：700。

合计 4400，是普通三消 300 分之外清楚可解释的技巧收益。

### E. 组合同时处理障碍、送达

- 第 1 轮：12 颗移除 1200＋两格糖霜各减 1 层 200＋两只箱子各减 1 点耐久 300＋其中一只箱子摧毁 150＋绑带解除 200=2050。
- 第 2 轮：6 颗移除＋糖霜减 1 层，合计 700×1.5=1050。
- 第 3 轮：3 颗移除，300×2=600。
- 划线＋区域主动组合奖 1600。
- 果篮送达 1 个 1000。
- 技巧第 3 连 700。

本次合计 7000。

### F. 彩虹批量转换

### 11.1 评分服务职责

ScoreService 只接收规则系统已提交的结果，输出评分条目与汇总；不扫描动画、不重算匹配、不改变补子或难度。

最少保留：runId、gameEpoch、actionId、waveId、eventId、instanceId / scoreTokenId、eventKind、真实变化量、基础值、倍率、最终分、原因。

同波实际变化由既有规则统一结算。计分依据最终 hpBefore→hpAfter 和消费集合，不能为了迎合计分规则另改阶段 A 的受击机制。

特殊生成与组合使用唯一结果事件；同一条逻辑事件回放两次只入账一次。初始化、无效交换、免费洗牌、编辑器预览和得分动画均不发正式分。

每波先汇总整数基础分，再用整数百分比计算并向下取整；固定奖单独入账，避免逐颗取整导致事件拆分影响结果。

### 11.2 计分与记录版本

改变任一计分值、倍率或资格规则，更新 scoreVersion。旧版成绩保留历史，不与新版直接比较。已通关解锁继续按稳定 levelId 保留，不能因计分改版取消通关。

预览模式输出同样的分数计算结果供调试，但不写正式纪录或奖励。

## 12. 高分与连消的演出规格

继续使用现有滚分和连消组件，先调整层级和调度。

### 12.1 信息层级

| 位置 | 信息 | 规则 |
| --- | --- | --- |
| 常驻 HUD | 目标、步数、总分 | 总分使用清楚的等宽数字；以当前画幅为参考可从 24–30 逻辑像素试起，必要时重新分配星条空间 |
| 分数附近 | 本次操作 +4400 | 操作累计，与局部每波得分分开；一次操作只保留一个汇总 |
| 棋盘上缘 | 8 连消 · 得分×3 | 固定一处更新，明确段数与倍率 |
| 棋盘上缘次级提示 | 技巧3连 · +700 | 动作结算时短暂出现，不常驻占据多行 |
| 清除局部 | 本波增分 | 默认一条，最多同时两条，多个清除区合并 |
| 棋盘中央 | 关键组合/里程碑 | 同时最多一个，短暂出现，不连续霸占中心 |
| 结算面板 | 总分、新纪录、最高连消、最佳技巧链 | 明细折叠，避免主面板变成调试表 |

不要持续逐颗弹出“+100”。清除数量可以很大，但数字显示对象要少。

### 12.2 滚分

- 逻辑 scoreTarget 立即按事件提交更新；displayScore 只负责展示。
- 得分发生后立即或下一显示帧开始追赶，不能等果冻飞到目标栏。
- 永远只有一个追赶控制器。新得分到来时更新目标，从当前显示值继续，不排队几十个旧 tween。
- 同局显示单调递增，不回零、不倒退；新局取消旧任务并重置。
- 最后一笔分数后约 200–400 毫秒追齐，硬上限 600 毫秒；大额分可以跳过中间整数，不需要每一分播一帧。
- 连消持续到来时保持连贯增长，不反复重启慢速缓动前段。
- 分数容器只做小脉冲：峰值约 1.04–1.07，80–100 毫秒抬起、120–160 毫秒回落；触发间隔建议不少于 150 毫秒。
- 使用固定宽度/等宽数字，滚分不能推动目标、步数或按钮的位置。

### 12.3 中央庆祝与连消升级

- 普通第 2 段主要更新上缘提示，不必每次中央大字。
- 可在第 3、5、8 段升级时短暂庆祝；更高段数继续记数，避免每段重复盖屏。
- 建议 80 毫秒出现＋180–240 毫秒停留＋100 毫秒退场。
- 宽度尽量不超过棋盘的 40%，高度约 1.1 格以内，减少第二行口号。
- 更高优先级的新消息替换当前消息，不叠三层，不积压播放队列。
- 局部得分约 350–500 毫秒，上移约 0.3–0.5 格；高频事件合并。
- 用数字增长、短促声调和轻微边缘响应表达升级，不持续白屏、闪烁、震屏。

### 12.4 掉落与工具区

保留整颗离场。棋盘下方设置可见掉落走廊，进入工具安全区域前淡出或回收。HUD 与工具层优先，离场代理不接收点击，也不与工具发生物理碰撞。

不因高分额外复制一批相同果冻落体；真实离场果冻已经是主要视觉反馈。

### 12.5 声音和震动建议

现有音轨未能从录屏验证。新增时建议使用柔软的短弹音、层数清除音和组合节点音；滚分音按合并后的奖励节拍播放，不按每一个整数播放。

限制同时发声与触发频率，例如数字滚分音不高于每秒 8 次，单类连消声有短冷却。高连消用有限音阶提升，封顶后保持舒适音域。震动可关闭，减少动态模式取消脉冲/震屏并保留数字信息。

### 12.6 通关数字同步

最终逻辑总分只确定一次。HUD 和结算面板共享同一显示状态，或面板打开后仅保留一个可见总分，避免录屏中出现的短时两套数字。

演出可按“操作小计 → 通关 +2000 → 余步 ×500 → 最终分”解释结果，逻辑奖励已经确定，不由动画逐项决定入账。

正常总时长建议约 0.9–1.4 秒，可点击跳过并直接显示已确定的最终值。跳过不重复结算，也不需要等全部离场果冻飞出画面才响应。

## 13. 高手的长期追求

普通关卡保留三星或既有评分分档。通过目标至少一星，二/三星阈值按每关新计分版本明确配置，并用实际试玩调整。

三星之后继续显示可比较的个人最佳目标；尚未通关的当局分数只表示进展，正式“新纪录”在有效通关后确认。

结算优先显示：总分、比旧最佳高多少、最高单次连消、最长技巧链。自然制造数量和主动组合次数放在展开明细里。

不要使用没有真实数据的“超过 99% 玩家”等语句；也不要用旧计分版本的最佳给新版做假突破。

## 14. 轻竞技的第一版范围

### 普通闯关

- 保留现有库存道具和已实现的辅助规则。
- 记录本关最佳与无道具最佳，细节可折叠。
- 不因使用道具取消视觉爽感，但记录 assistanceFlags。
- 普通关不同随机种子的个人纪录可比较，但不宣传为严格相同条件竞技。

### 标准挑战

先做 3 个精选挑战：偏特殊构造、偏障碍处理、偏综合送达。具体布局与目标由编辑器制作并测试，使用玩家已学会的机制。

每个挑战发布配置固定：

- challengeId、关卡内容修订、玩法规则版本、计分版本。
- 初始棋盘或确定生成结果、seed、随机算法版本。
- 步数、普通类型集合、生成权重和正式重力规则。
- 无盘外库存道具、无额外步数、无开局赠送增益；设计者明确预置的特殊属于关卡本身，对所有挑战者一致。

棋盘内自然制造与组合完全允许。不限重试，每次使用同一挑战配置和种子；练习同一局面属于预期玩法。

暂停和思考不扣分，不拿操作耗时作为破同分条件。

### 排序规则

1. 只有目标完成且规则执行有效的局进入通关成绩榜。
2. 总分高者优先。
3. 同分时剩余步数较多者优先。
4. 仍相同则并列。

未完成的局保留个人尝试记录，不用高分压过成功通关成绩。

### 当前与后续能力分开

第一版提供真实本机纪录和固定挑战历史。若已有可用后端，可在独立后续步骤接入真实排行榜；否则只预留成绩提交与回放接口，不伪造联网状态、名次或其他玩家。

上线可信跨玩家排行榜前，需要以可信服务端规则验证输入回放与结果；客户端传来的总分或哈希不能自行证明可信。当前不为此扩建庞大的社交/实时对战系统。

固定 seed 的含义是“相同配置与相同输入可复现”，不是“不同选择的玩家每一步看到相同落子”。玩法随机与视觉随机分离。
